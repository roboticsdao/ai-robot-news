CyberSecurityNews — Hackers Can Take Full Control of Unitree G1 Humanoid Robots Over Bluetooth

Security researchers uncovered a critical attack chain dubbed UniBLEed, tracked as CVE-2026-76639 and CVE-2026-76640, affecting Unitree G1 humanoid robots. The multi-stage exploit allows a nearby attacker over Bluetooth Low Energy (BLE) to bypass pairing, query the cloud API without proper robot-ownership validation to retrieve device-specific AES encryption keys, and send malicious Wi-Fi configurations. A buffer overflow in the Wi-Fi SSID handler and a path-traversal flaw in the ChatGo AI service allow attackers to achieve root-level code execution on the robot's locomotion computer. Unitree reportedly implemented an ownership-binding check for the cloud endpoint and issued patches prior to public disclosure.
