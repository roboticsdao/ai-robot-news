Security Affairs — Hack One Robot, Reach the Next: Unitree G1 Security Flaws

Security researcher Olivier Laflamme discovered two critical vulnerabilities, CVE-2026-76639 and CVE-2026-76640, affecting the Unitree G1 humanoid robot, enabling unauthenticated root access via Ethernet, Bluetooth, and cloud API flaws. The exploit chains allow arbitrary file writing through the AI chatbot service and leverage a decryption oracle in Unitree's cloud endpoint to obtain AES-128 keys without proper ownership verification. This further permits Wi-Fi configuration injection and a buffer overflow in the Bluetooth server to execute arbitrary commands with root privileges, presenting wormable risks among nearby robots.
