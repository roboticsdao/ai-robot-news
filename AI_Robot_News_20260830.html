Security Affairs — Hack One Robot, Reach the Next: Unitree G1 Security Flaws

Security researcher Olivier Laflamme discovered vulnerabilities, designated CVE-2026-76639 and CVE-2026-76640, enabling unauthenticated root access to Unitree G1 humanoid robots via Bluetooth range, cloud APIs, and firmware flaws. The exploit chains utilized unvalidated file uploads, an insecure Bluetooth cryptographic key bootstrap decryption oracle via the cloud API, and a stack-based buffer overflow. The researcher demonstrated that a compromised robot could potentially propagate the exploit to other G1 units within Bluetooth range.
