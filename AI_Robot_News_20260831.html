The Hacker News — Two Unitree G1 EDU Humanoid Robot Flaws Enable Root RCE, One Starts Over Bluetooth

Security researcher Olivier Laflamme disclosed two independent root remote code execution chains affecting the Unitree G1 EDU, tracked as CVE-2026-76639 and CVE-2026-76639 (noted as CVE-2026-76640 for the Bluetooth chain). The first vulnerability involves a path-traversal condition in chat_go reaching bashrunner to execute root commands on the Locomotion PC. The second flaw begins with a Bluetooth Low Energy (BLE) proximity write that bypasses pairing and exploits a cloud authorization authorization flaw, allowing unauthorized key recovery due to a missing ownership check. The recovered key enabled Wi-Fi provisioning, where a buffer overflow produced root execution. Laflamme published the findings on August 27, 2026, noting that Unitree patched the cloud account ownership check in July 2026, though exact fixed firmware releases remain unverified.

总结：安全研究员Olivier Laflamme披露了影响宇树G1 EDU的两条独立根远程代码执行（RCE）漏洞链，分别被追踪为CVE-2026-76639和CVE-2026-76640。 第一个漏洞涉及chat_go中的路径遍历条件，可达bashrunner并在Locomotion PC上执行根权限代码。 第二个漏洞始于低功耗蓝牙（BLE）写入，绕过了配对机制并利用了云授权漏洞，由于缺少所有权检查而允许未授权的密钥恢复。 恢复的密钥使Wi-Fi配置得以进行，并在其中触发了缓冲区溢出以实现根执行。 Laflamme于2026年8月27日发布了研究成果，指出宇树已于2026年7月修补了云账户所有权检查，但确切的修复固件版本尚未得到验证。
