Ubergizmo JAPAN — 三菱電機、災害救助ロボットの「聴覚」を強化する新AI「TUSS」を発表

三菱電機はCEATEC 2026に出展し、機械に複雑な環境の音を聞き分ける能力を与える新たなAI技術「Task-Aware Unified Source Separation（TUSS）」を発表した。 この技術は2026年8月31日に米マサチューセッツ州ケンブリッジの研究所と共同で発表されたもので、1つのマイクと1つのAIモデルだけで、抽出したい音源を選択して騒がしい環境中から声や機械音などを分離できる。 CEATEC 2026のデモでは災害救助活動と産業機器監視の2つの応用例が紹介され、同技術はCEATEC 2026イノベーションアワードで総務大臣賞を受賞した。 災害現場の音声から人間の声を分離して救助隊や救助ロボットの判断を支援するほか、工場の騒音から機械の異常音を特定することに利用される。 三菱電機は2027年に自社工場でこの技術を導入し、その後他メーカーへ提供を検討する予定である。 同社ブースではCP Roboticsと共同開発したヒューマノイドロボットなども展示された。

总结：三菱电机在日本CEATEC 2026展会上推出了名为“Task-Aware Unified Source Separation（TUSS）”的新AI技术，旨在赋予机械在复杂环境中辨别声音的能力。 该技术由三菱电机于2026年8月31日与其位于美国马萨诸塞州剑桥的研究所共同发布，仅需一个麦克风和一个AI模型即可从嘈杂环境中分离特定声音。 在CEATEC 2026展会上，TUSS展示了灾害救援和工业设备监控两个应用场景，并荣获CEATEC 2026创新大奖的总务大臣奖。 该技术能够从灾害现场的嘈杂背景音中提取人声以协助救援人员和救助机器人，亦能从工厂噪音中分离出机械运转异常音。 三菱电机计划于2027年首先在自家工厂引入该技术，随后考虑向其他制造商提供。 展会现场还展出了与CP Robotics共同开发的人形机器人等技术。

Mitsubishi Electric has developed an industry-first processing system that seamlessly connects humanoid robots and CNC machine tools via physical AI.
